# Contact Form 7 Styling & Frontend Guide

Use this skill to generate modern, responsive, and accessible Vanilla CSS styles and JavaScript event listeners for Contact Form 7 forms.

---

## Core CF7 CSS Selectors

Contact Form 7 wraps form elements in specific CSS classes:

| Selector | Element | Description |
| :--- | :--- | :--- |
| `.wpcf7` | Outer wrapper `<div>` | Top-level container generated by shortcode |
| `.wpcf7-form` | `<form>` element | The form tag itself |
| `.wpcf7-form-control` | Inputs, Textareas, Selects | Base class for all CF7 input fields |
| `.wpcf7-text` | `<input type="text/email/tel/url">` | Standard text-based inputs |
| `.wpcf7-textarea` | `<textarea>` | Multiline text inputs |
| `.wpcf7-select` | `<select>` | Dropdown elements |
| `.wpcf7-checkbox` | `<span class="wpcf7-checkbox">` | Checkbox container |
| `.wpcf7-radio` | `<span class="wpcf7-radio">` | Radio buttons container |
| `.wpcf7-file` | `<input type="file">` | File upload element |
| `.wpcf7-submit` | `<input type="submit">` | Submit button |
| `.wpcf7-not-valid-tip` | `<span>` below invalid field | Field validation error text |
| `.wpcf7-response-output` | `<div>` at bottom of form | Status response banner |
| `.wpcf7-spinner` | `<span>` beside submit button | Submission loading indicator |

## JavaScript Custom DOM Events

Contact Form 7 emits standard CustomEvent instances on the `document` node:

| Event Name | Trigger Condition |
| :--- | :--- |
| `wpcf7mailsent` | Mail was successfully sent |
| `wpcf7mailfailed` | Form valid, but `wp_mail()` failed |
| `wpcf7invalid` | Form failed validation |
| `wpcf7spam` | Form flagged as spam |
| `wpcf7submit` | Form submission initiated |

### Conversion Tracking & Redirect Example:

```javascript
document.addEventListener('DOMContentLoaded', function() {
  document.addEventListener('wpcf7mailsent', function(event) {
    // Optional: Filter by specific Form ID
    // if (event.detail.contactFormId !== '123') return;

    console.log('CF7 submission successful:', event.detail);

    // 1. Google Analytics 4 (GA4) Event
    if (typeof gtag === 'function') {
      gtag('event', 'generate_lead', {
        form_id: event.detail.contactFormId,
        form_name: 'Contact Inquiry'
      });
    }

    // 2. Redirect to Thank You page (if required)
    // window.location.href = '/thank-you/';
  }, false);
});
```
